## 方案 A：令牌对齐（最小侵入）⭐ 推荐先看

**思路**：只改各项目的令牌文件，一行布局不动。主色/中性阶/圆角/阴影全部对齐嘉禾基准，视觉立即统一。

| 项目 | 改动文件 | 改动量 |
|---|---|---|
| 禾语农产品AI客服 | `src/styles/design-tokens.css`（改 ~12 个色值 + 圆角映射） | ~20 行 |
| 禾语农产品AI运营助手 | `src/app/globals.css` 的 `:root`（品牌色→嘉禾绿，侧栏保留深色但换嘉禾绿系） | ~15 行 |
| 禾语农产品知识库 | `styles.css` 的 `:root`（--brand→嘉禾绿，圆角向嘉禾阶梯靠一档） | ~12 行 |
| 三项目 | 顶栏/侧栏品牌位加嘉禾 logo + 平台名小字（每处 1-3 行） | 3 处 |

- **工时**：合计约 0.5 天；**风险**：极低（纯色值/圆角替换，无结构改动，回滚=还原令牌文件）
- **收益**：三项目瞬间同主色、同中性阶、同圆角语言
- **局限**：布局范式仍不统一（运营助手仍是深侧栏）；组件细节（间距/字号/阴影）仍有差异；各项目令牌**命名不统一**（`--color-primary` vs `--brand`）的问题不动

## 方案 B：结构对齐（布局 + 组件规范统一）

**思路**：A 的全部 + 统一「禾语农产品壳」布局规范与组件规格，让三项目像同一个产品的三个模块。

1. **统一壳**：顶栏 60px——嘉禾 logo + 「禾语农产品智能商管平台」+ 当前子系统名 + 「返回门户」链接；面包屑规范（门户 / 子系统 / 页面）
2. **禾语农产品AI运营助手侧栏改造**：深 slate 侧栏改**浅色侧栏**（与另两项目顶栏范式拉齐），或保留深侧栏但换嘉禾绿深色系（`#1B5E20` 底）——样稿中两种都展示了倾向后者（改动小、后台感保留）
3. **组件三件套统一**：按钮（高度 36/30、圆角 10、主色嘉禾绿）、徽章（五态统一）、卡片（白底、16px 圆角、同阴影档）——各项目 ui 原语的规格值对齐
4. **页头统一**：标题 20px + 副标题 12-13px + 右侧操作区，三项目同构
5. 字号对齐：正文 ≥14px、辅助 ≥12px（客服项目现状 13-14，运营/智库偏小需上调）

- **工时**：每项目 1-2 天（运营助手动侧栏最重）；**风险**：中（动布局，需逐页面回归）
- **收益**：跨项目迁移零学习成本；为方案 C 打基础
- **局限**：各项目仍是各自的代码/组件实现，无共享层，长期有漂移风险

## 方案 C：品牌体系（共享令牌包 + 规范手册）

**思路**：B 的全部 + 建品牌资产层与跨项目共享机制，一次性解决"长期一致"。

1. **共享令牌包**：`jiahe-brand-tokens/`（一份 CSS，三项目以同版本号引用/拷贝）——含色/字/圆角/阴影/动效/壳规范/组件规范；版本号管理，改令牌=发版本
2. **品牌资产**：嘉禾 logo 三形态（横版用于顶栏/单标用于favicon/反白用于深色底）；统一空态插画风格（线条+嘉禾绿）；骨架屏/动效统一（`--ease-out` + duration 三档）
3. **跨项目导航约定**：任一子系统顶栏常驻「返回门户」+ 平台名，形成"门户↔子系统"双向可达
4. **《嘉禾前端规范手册》**：命名规范、组件用法、模式（表单/表格/空态/加载）、审查清单（新页面上线前对照）
5. 运营助手 lucide 图标与另两项目 SVG 注册表统一为同一套线性图标风格（保留各自实现，规范笔触/粗细）

- **工时**：合计 3-5 天；**风险**：中高（体系化改动，建议分项目灰度：先客服后运营再智库）
- **收益**：真正"一个品牌三个产品"；新项目/新页面直接套规范，不再各自为政
- **局限**：投入最大；若三项目后续独立演进，需要维护令牌包版本同步纪律

## 三版对比与建议

| | A 令牌对齐 | B 结构对齐 | C 品牌体系 |
|---|---|---|---|
| 改动性质 | 只改令牌文件 | 令牌 + 布局 + 组件规格 | B + 共享层 + 规范手册 |
| 工时 | 0.5 天 | 3-4 天 | 3-5 天 |
| 风险 | 极低 | 中 | 中高 |
| 视觉统一度 | 色系统一，布局仍旧 | 布局组件都统一 | 完整品牌体系 |
| 长期防漂移 | 无 | 弱 | 强（版本化令牌包） |
| 回滚成本 | 还原 3 个文件 | 逐项目 git revert | 停止引用令牌包 |

**建议路径**：**A 立即做**（当天见效、零风险）→ 审查 demo 后若满意结构统一度再上 **B**（可先做运营助手侧栏这一个重点）→ C 作为季度目标（尤其如果后续还要加新项目/新页面）。

> 三版 demo 样稿已按同内容（门户 + 三项目代表页）渲染，可直接对比观感后定稿。
