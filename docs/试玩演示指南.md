## 一、启动

### 方式 A：一键启动（推荐）

**双击项目根目录的 `启动项目.bat`**

它会依次做四件事：
1. 检查 MySQL（127.0.0.1:3306）是否在跑
2. 首次运行时自动 `uv sync` 安装客服后端依赖
3. 打开 3 个新窗口，分别启动客服后端 / 电商后端 / 客服前端
4. 等 18 秒后自动打开浏览器 `http://127.0.0.1:5173/`

> 停止服务：**关闭那 3 个服务窗口**即可。

### 方式 B：手动启动（3 个终端）

```bash
# ① 客服后端（含数字人接口与 WebSocket）→ 18082
cd F:\customer-service-backend
uv run uvicorn api.app:app --host 127.0.0.1 --port 18082

# ② 电商业务后端 → 18081
cd F:\customer-service-backend\external\ecommerce-service-backend
uv run python main.py

# ③ 客服前端 → 5173
cd F:\customer-service-backend\external\customer-service-frontend
npm run dev
```

### 前置条件

| 依赖 | 要求 | 现状 |
|---|---|---|
| MySQL | 127.0.0.1:3306，root / 123456 | 本机为 Windows 服务 `mysqld`，已在运行 |
| 数据库 | `customer_service` + `commerce` | ✅ 已初始化并含演示数据 |
| uv | 用于两个 Python 后端 | 已安装 |
| Node.js | 用于前端 | 已有 |

**只能用 `127.0.0.1` 或 `localhost` 访问**，不要用局域网 IP ——
魔珐星云 SDK 强制要求 localhost 或 https，用 IP 会直接报错。

## 三、数字人连不上时怎么查

面板下方会**直接显示错误码和原因**，对照下表：

| 现象 / 错误 | 原因 | 处理 |
|---|---|---|
| `浏览器不支持 WebGL 2.0` | 浏览器过旧或禁用了硬件加速 | 换较新版 Chrome / Edge；检查浏览器设置里的「使用硬件加速」 |
| `SDK 错误 10003：创建会话失败` | App ID / App Secret 不对 | 去星云控制台核对「应用中心 → 驱动应用」的密钥 |
| `SDK 错误 10001：容器不存在` | 页面结构异常 | 刷新页面 |
| `SDK 错误 10005：超出房间并发限制` | 之前连接没释放 | 点「销毁数字人」或刷新页面 |
| 初始化成功但**说话没反应** | 驱动应用的**模型权限**未开通 | 去控制台检查该应用的模型权限 |
| `后端未下发 App Secret` | 演示模式未开 | 把 `.env` 的 `XMOV_ALLOW_SECRET_TO_CLIENT` 设为 `true` 后重启后端 |
| `数字人 SDK 脚本加载失败` | 网络问题 | 检查能否访问 `media.xingyun3d.com` |
| `数字人资源下载超时` | 网络慢 | 重试；或检查 `nebula-agent.xingyun3d.com` 连通性 |

**需要更详细的日志时**：把 `src/App.vue` 里 `initDigitalHuman()` 的
`enableLogger: false` 改成 `true`，然后按 F12 看 Console。
