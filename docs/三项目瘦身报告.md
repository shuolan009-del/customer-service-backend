## 五、如实说明（执行中发现的情况）

1. **`"docs` / `"test` "错名目录"是误判**：`git ls-files`/`git status` 输出中路径前的 `"` 是 `core.quotePath` 对**非 ASCII 文件名**的转义显示，并非真实目录名。csb 的 9 份中文文档、kb 的中文文件名脚本一直都在正确的 `docs/`、`test/` 里，没有任何文件被误移动或误删。
2. **ecommerce `web/docs/verify/overview.md` 有一处未提交修改**（标题改名「电商运营助手」→「禾语农产品AI运营助手」），随整个目录获批删除而丢弃；该文件已入库，历史可查。
3. 三个仓库工作树里都有**其他会话的未提交 WIP**（嘉禾平台相关），瘦身提交严格只暂存删除/文档路径，WIP 原样保留未纳入。
4. csb 有 3 份文档（`docs/前端代码审查报告-多轮.md`、`docs/前端优化交付说明-对话流重构.md`、`docs/嘉禾智能商管平台-命名与对接规范.md`）的正文里引用了被删的一次性脚本（verify-*.mjs 等）——那是**历史验证记录**，为保持记录真实性未改写，仅在此告知。

## 六、回滚方法

```bash
# 单仓库整体回滚（删除操作全部还原，WIP 不受影响）
git revert <瘦身commit>          # csb: e5d5df2 / ecommerce: ff7bdca / kb: 27262a5

# 或硬回退到瘦身前（会丢弃该 commit 之后的本地提交，慎用）
git reset --hard HEAD~1

# 恢复单个文件到瘦身前版本
git checkout HEAD~1 -- <文件路径>
```
