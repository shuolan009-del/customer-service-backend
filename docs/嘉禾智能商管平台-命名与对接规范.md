## 八、已知坑（排障记录）

1. **vite 6.4.4 本机不调用顶层 `configureServer`**（最小复现验证过，静默失效）——必须写成**插件钩子**形式（`plugins: [vue(), { name, configureServer }]`）。
2. **connect 的 `use(path)` 匹配后 req.url 仍带前缀**（剥前缀是 express Router 的行为），拼文件路径前需手动 `replace(/^\/tianshe/, '')`。
3. **Node Windows 路径分隔符**：`normalize(join(...))` 产物是反斜杠，与正斜杠常量做 `startsWith` 会静默失配 → 全部 404；KB_DIR 必须同样 normalize。
