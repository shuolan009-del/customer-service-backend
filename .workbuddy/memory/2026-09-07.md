## 停止服务的正确顺序（重要）
uvicorn 以 `reload=True` 运行时会派生子进程，**只 kill 父进程（reloader）会留下子进
程继续占端口**。可靠做法：
1. 先停掉启动它的后台任务（TaskStop），让整棵进程树退出；
2. 再按端口 kill 残留 PID。
- git bash 里 `taskkill /F /PID x` 会被路径转换吞掉开关，需先 `export MSYS_NO_PATHCONV=1`。
- `wmic` 被安全策略禁用，不可用。
- netstat 在进程退出后可能短暂仍显示 LISTENING，稍等即消失，不要误判为 kill 失败。
